# 音效文件目录

将下载的小森平音效 .wav 文件放入此目录即可自动加载。

## 快速开始

```bash
# 在项目根目录运行，查看每个音效的下载指引
bash download_sounds.sh
```

- 主菜单: 古琴独奏，悠远空灵，水墨画意境，缓慢节奏
- 战斗: 密集鼓点+琵琶扫弦，紧张急促，武侠战斗氛围
- Boss: 大鼓重击+唢呐高亢，压迫感，黑暗水墨风格
